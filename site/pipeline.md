Scripts are numbered, standalone and self-contained, with settings in a `CONFIG` block at the top of each. Python scripts use the `lg-eeg` conda environment (`environment.yml`). DCM scripts need MATLAB with SPM12.

## Setup

```bash
conda env create -f environment.yml
conda activate lg-eeg
bash scripts/00_download.sh            # LG session + sourcedata from OpenNeuro (~10 GB)
python scripts/01_inspect_triggers.py
python scripts/02_preprocess.py        # all participants (or: sub-01)
```

## DCM (MATLAB / SPM12)

Run in this order from `scripts/dcm/`:

1. `dcm_01_prepare.m`: FieldTrip → SPM conversion, head model.
2. `dcm_02_fit.m`, then `dcm_03_peb.m`: main model (0/1 coding), PEB + BMR.
3. `dcm_04_robustness.m`: window, IPL location, mean removal, spatial model.
4. `dcm_05_surprise.m` (0–600 ms), `dcm_06_early.m` (0–250 ms), then `dcm_07_search_full.m`: surprise and interaction codings.

Fits take 30–75 min per analysis with `parfor`. Each script skips participants that are already fitted.

## Analysis notebook

`notebooks/results_analyses.ipynb` re-derives every Results number from the saved derivatives and runs the validation simulations. It is generated by `notebooks/build_results_notebook.py`, so edit the builder, then regenerate:

```bash
python notebooks/build_results_notebook.py
cd notebooks && jupyter nbconvert --to notebook --execute results_analyses.ipynb \
    --output results_analyses_executed.ipynb --ExecutePreprocessor.timeout=1800
```

Flags at the top (`RECOMPUTE_ALL_CV`, `RECOMPUTE_SOURCE`) rerun the expensive steps instead of loading saved results. A full run takes about 10 minutes.

## Building this site

```bash
npm install -g mystmd      # once
myst start                 # live preview at http://localhost:3000
myst build --html          # static site in _build/html
```

The site reads the executed notebook as is, so rerun the notebook before rebuilding if numbers change.
